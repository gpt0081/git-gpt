# Changelog

## 0.3-assets

- Added seven standalone OBJ/MTL low-poly models: house, tree, longboat, wall, rock, soldier and shield.
- Added nine 256×256 albedo textures and six matching normal maps.
- Integrated imported models into the village, forests, walls, shoreline, units and landing boats.
- Added textured materials for terrain, cliff, sea, plaster, roof, wood, foliage, sailcloth and iron.
- Added mobile import settings for texture compression, mipmaps, normal maps and mesh compression.
- Preserved primitive fallbacks when an imported asset is missing.
- Added deterministic model and texture generators for source-only Git checkouts.

## 0.2-manual

- Rebuilt the project as a Unity 6.3 LTS runtime-generated prototype.
- Added deployment, three allied classes, landing boats, raiders, combat, abilities and results.
