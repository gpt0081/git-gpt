FJORDFALL UNITY 3D 0.2 - 수동 테스트판

권장 Unity: Unity 6.3 LTS 6000.3.19f1

1. ZIP을 영문 경로에 압축 해제합니다.
   Mac 예시: ~/Unity/Projects/Fjordfall-Unity3D-0.2-manual
   Windows 예시: D:\Unity\Projects\Fjordfall-Unity3D-0.2-manual
2. Unity Hub > 프로젝트 > 추가 > 디스크에서 프로젝트 추가를 누릅니다.
3. 압축을 푼 최상위 폴더를 선택합니다.
4. 첫 실행 시 패키지와 스크립트 임포트가 끝날 때까지 기다립니다.
5. 씬이 자동 생성됩니다. 생성되지 않으면 상단 메뉴 Fjordfall > 1. 프로젝트 준비를 누릅니다.
6. 중앙 상단 ▶ 버튼으로 실행합니다.
7. 전투 전 배치 화면에서 분대 버튼을 누르고 섬 위를 눌러 위치를 정합니다.
8. 전투 시작을 누릅니다.
9. 전투 중 분대를 선택하고 섬 위를 눌러 이동합니다.
10. Android Build Support가 설치되어 있으면 Fjordfall > 2. Android APK 빌드로 APK를 만듭니다.

현재 구현:
- 직교 카메라 3D 디오라마 섬
- 비, 수면 움직임, 안개, 저채도 팔레트
- 검병, 창병, 궁병 3개 분대
- 전투 전 배치와 분대 선택 이동
- 병과별 사거리와 자동 공격
- 적 수송선 4척과 상륙 병력
- 병과별 액티브 능력
- 승리, 패배, 일시정지, 재시작
- 외부 모델/텍스처/유료 에셋 없음

알려진 한계:
- NavMesh가 없어 분대가 건물을 우회하지 않습니다.
- 애니메이션은 절차형 펄스 수준입니다.
- 실제 Unity 컴파일은 이 생성 환경에서 실행 검증하지 못했습니다.
- 첫 빨간 Console 오류가 있으면 오류 전문과 화면을 보내십시오.
