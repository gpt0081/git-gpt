FJORDFALL UNITY 3D 0.3 - 외부 모델·텍스처 통합 테스트판

권장 Unity: Unity 6.3 LTS 6000.3.19f1

1. ZIP을 영문 경로에 압축 해제합니다.
2. Unity Hub > 프로젝트 > 추가 > 디스크에서 프로젝트 추가를 누릅니다.
3. 압축을 푼 최상위 폴더를 선택합니다.
4. 첫 실행 시 패키지, OBJ 모델과 PNG 텍스처 임포트가 끝날 때까지 기다립니다.
5. 씬이 자동 생성되지 않으면 Fjordfall > 1. 프로젝트 준비를 누릅니다.
6. 중앙 상단 ▶ 버튼으로 실행합니다.

현재 구현:
- 직교 카메라 3D 디오라마 섬
- 검병, 창병, 궁병 3개 분대와 적 상륙전
- OBJ 외부 모델 7종
- PNG 알베도 9종과 노멀맵 6종
- 지형, 절벽, 물, 집, 나무, 성벽, 병사와 수송선 외부 자산 적용
- 모델 또는 텍스처 누락 시 절차형 기본 도형 fallback

알려진 한계:
- NavMesh가 없어 분대가 건물을 우회하지 않습니다.
- 골격 애니메이션은 아직 없고 전투 모션은 절차형입니다.
- 실제 Unity 컴파일은 이 생성 환경에서 실행 검증하지 못했습니다.
- 첫 임포트는 v0.2보다 오래 걸릴 수 있습니다.
