# Fjordfall Unity 3D 0.2 Manual Test

A self-contained Unity 6.3 LTS tactical-island prototype generated entirely from runtime primitives. The first import creates `Assets/Scenes/Fjordfall.unity` automatically.

## Open

1. Use Unity **6.3 LTS 6000.3.19f1**.
2. Open this directory from Unity Hub.
3. Wait for script compilation.
4. Run `Fjordfall > 1. 프로젝트 준비` only if the play scene was not generated automatically.
5. Press Play.

## Scope

- orthographic low-poly island diorama
- deployment phase
- sword, spear and bow squads
- formation movement
- raider longboats and landing waves
- automatic combat and class abilities
- rain, fog, water motion and ripple effects
- pause, victory, defeat and restart

No reference-game art, logos, icons, characters or level data are included.
