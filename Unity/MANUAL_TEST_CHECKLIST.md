# 수동 테스트 체크리스트

테스트 기기와 Unity 버전을 먼저 기록한다.

- [ ] 프로젝트가 빨간 Console 오류 없이 열린다.
- [ ] `Assets/Scenes/Fjordfall.unity`가 자동 생성된다.
- [ ] Play 후 5초 이내 배치 화면이 보인다.
- [ ] 검병·창병·궁병 버튼으로 선택을 바꿀 수 있다.
- [ ] 배치 중 섬을 누르면 선택 분대가 이동한다.
- [ ] 전투 시작 후 적 수송선이 네 방향에서 순차 접근한다.
- [ ] 수송선이 해안에 닿으면 적이 상륙한다.
- [ ] 검병·창병·궁병의 공격 사거리가 다르게 보인다.
- [ ] 분대가 진형을 유지하며 이동한다.
- [ ] 능력 버튼이 선택 병과에 따라 달라진다.
- [ ] 일시정지와 재개가 작동한다.
- [ ] 적을 모두 제거하면 승리 화면이 나온다.
- [ ] 아군 전멸 시 패배 화면이 나온다.
- [ ] 다시 시작이 정상 작동한다.
- [ ] 10분 플레이 중 프리징이나 크래시가 없다.

피드백에는 장면, 재현 절차, 기대 결과, 실제 결과, 스크린샷을 포함한다.
