# ACCEPTANCE CRITERIA

- AC-001: 프로젝트를 열고 5초 이내에 배치 화면을 표시한다.
- AC-002: 세 분대 모두 선택과 지형 이동 명령을 받는다.
- AC-003: 전투 시작 이후 3초 이내 첫 수송선이 움직인다.
- AC-004: 네 척의 수송선이 각각 상륙 병력을 생성한다.
- AC-005: 세 병과의 공격 사거리가 육안으로 구분된다.
- AC-006: 살아 있는 병사는 분대 중심 기준 진형 위치로 복귀한다.
- AC-007: 일시정지 중 전투 시간과 이동이 정지한다.
- AC-008: 승리와 패배가 상호 배타적으로 한 번만 표시된다.
- AC-009: 10분 연속 실행 중 크래시와 무한 증가 객체가 없어야 한다.
